## Internship Python Assignment

This repository contains Python scripts solving the Section B tasks of the internship Assessment Test.

## Scripts

1. **loyalty_points.py** - Calculates loyalty points based on membership tier and total spent.
2. **smart_traffic_light.py** - Simulates a smart traffic light system with emergency vehicle handling.
3. **inventory_alert.py** - Alerts for out-of-stock or low-stock items in an inventory list.

## How to Run

Run each script using Python 3:

```bash
python loyalty_points.py
python traffic_light.py
python inventory_alert.py
